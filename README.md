# Personal Website & Research Portfolio

Personal portfolio and academic website for **Dr. Chia Sin Liew**, Senior Bioinformatician and Computational Biologist. Built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/), hosted automatically via [GitHub Pages](https://pages.github.com/).

## 🛠️ Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)
- **Base Theme:** Customized version of [Dante](https://github.com/JustGoodUI/dante-astro-theme) by JustGoodUI
